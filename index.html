🟢 通話中の部屋

🛰 ロビーに接続中…

部屋をタップするとそのまま入室します。通話中は確認のうえ移動します。

このサイトはアクセス測定に Cloudflare Web Analytics を利用しています（Cookie不使用・個人を特定する情報は取得しません）。

🦞 これはなに？

同じ部屋名を開いた人どうしが、そのまま音声でおしゃべりできる実験的なミニ通話Webアプリです。サーバを持たず、ブラウザ同士が直接つながります（WebRTC・P2P）。配信アプリ POPOPO にインスパイアされて作りました。

💡 部屋名はURLの一部（末尾の #◯◯）。共有リンク＝その部屋のURLなので、開けば同じ部屋に入れます。

⚠️ 実験中です。ご利用は自己責任で！

つかいかた

まず（共通）

  • 名前とアバター（絵文字）を決める（ブラウザに保存され、次回も引き継ぎます）

部屋を作る

  1. 部屋名を入れて「参加する」→ マイクを許可
  2. 同じ部屋名・共有リンク・QRコードを相手に渡す

部屋に入る

  • 「通話中の部屋」から選んでタップ（共有リンク／QRからも入れます）→ マイクを許可
できること
  • 🟢 ロビー：いま通話中の部屋が一覧で見える（続いている時間も）
  • 👥 参加者：名前・絵文字が出て、話している人の絵文字が跳ねる／ミュートも表示
  • 🌱 育てる：使うほどあなたの絵文字が成長（🌱→🌿→🌷→❓）
しくみ・プライバシー
  • 音声はブラウザ間で直接やりとり（サーバに録音・保存されません）
  • 部屋名を知っている人は誰でも入れます。ロビーには部屋名・参加者・どのくらい続いているか・話しているかどうかが表示されます（＝内緒の部屋ではありません）
  • アクセス数の測定に Cloudflare Web Analytics を使用（Cookie不使用・個人は特定しません）
注意（実験版）
  • 実験中のため、切断や不具合が起きることがあります
  • マイクの許可が必要です。Safari / Chrome で開いてください（アプリ内ブラウザは不可）
  • iPhoneでは「音声を有効化」ボタンが出ることがあります
  • 快適なのは 4〜6人 くらいまで（全員が全員につながる方式のため）
  • 回線によっては稀につながらないことがあります
  • 過去の会話は残りません（録音保存なし）
  • ブラウザは別々に扱われます：スマホとPCは別、PCでもSafari/Chromeなど別ソフトは別、同じChromeでもプロファイルが違えば別ブラウザ扱い（名前や成長は引き継がれません）
  • 利用で生じた損害は自己責任で。一般的なモラルを守ってお使いください。（利用ガイドライン作成中）

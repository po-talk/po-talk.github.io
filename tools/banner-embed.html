🦞 ライブ中バナーぽっと通話

自分の部屋がいま通話中かどうかを表示する小さなバナーを、ブログや Google サイトに貼れます。 部屋のリンクを貼ると、下にプレビューと貼り付け用コードが出ます。

① 部屋のリンクを貼る

部屋のリンクを貼ってください

どこに貼れる？

Google サイト「挿入 → 埋め込む → 埋め込みコード」に上のコードを貼る（「URL を埋め込む」ではなくコードのほう）
はてなブログ 等HTML を貼れるブログなら OK（<iframe> がそのまま動く）
自分で建てた WordPressカスタム HTML ブロックに貼る
WordPress .com 無料iframe が使えないことが多い（有料/プラグインが必要）
GitHub の READMEiframe・JavaScript が除去されるので動きません（画像＋リンクなら可）

仕組み：部屋名を伏せた値（ハッシュ）で公開リレーの在室を読み取るだけ。サーバは介しません。 15秒以内に在室があれば「いま通話中」、無ければ「静か」。タップでその部屋が開きます。
